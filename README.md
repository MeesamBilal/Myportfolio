# Meesam Bilal - Portfolio (flat version)

ALL files live in ONE folder, no sub-folders. Upload every file to the repo root, next to index.html.

## GitHub upload (web)
1. Open your repo > Add file > Upload files.
2. Open this folder, press Ctrl+A to select ALL files, and drag them into the GitHub page. (Do not drag the folder itself.)
3. Wait until all 25 files are listed, then click Commit changes.

## Deploy
- Vercel: Add New > Project > pick the repo > Framework Preset "Other" > Deploy.
- GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).

To change a picture/video, upload a new file with the SAME name.
